# 會議電子簽到網頁（Google Apps Script）

## 這個技能做什麼

- 與會者用手機掃 QR Code → 填姓名（必填）、單位、職稱（選填）→ 用手指手寫簽名 → 送出。
- 簽名存成白底 PNG，放在使用者雲端硬碟「會議簽到 / 會議名稱」資料夾，檔名為「時間_姓名_單位.png」。
- **每場會議自動建立一份獨立的 Google 試算表**「簽到表_會議名稱」（放在該場會議資料夾），欄位：序號、簽到時間、姓名、單位、職稱、簽名（儲存格內直接顯示簽名圖）、簽名檔連結、檔案ID。
- 綁定 Apps Script 的那份試算表是「會議簽到總覽」：列出所有會議、簽到人數、最後簽到時間與連結；上方「簽到工具」選單可「建立會議並產生簽到 QR Code」（輸入會議名稱 → 自動建立該場試算表、QR Code 圖存到該場資料夾），也可對選取的會議一鍵匯出 **Excel（.xlsx）與 PDF 簽到表**（含簽名圖，A4 可列印），存到該場會議資料夾。
- 不用 Google 表單：表單沒有手寫簽名題型，檔案上傳題又強制登入。名冊試算表就等同「表單回應試算表」。
- 同一個網址可用於多場會議：網址後加 `?m=會議名稱`。

## 檔案

| 檔案 | 用途 |
| --- | --- |
| `assets/Code.gs` | Apps Script 後端：存簽名檔、寫試算表（含儲存格簽名圖）、`setup()` 首次授權、`onOpen()` 選單與 Excel／PDF 匯出 |
| `assets/Index.html` | 手機簽到頁（手寫簽名板、重簽、送出、完成頁） |
| `references/deploy-guide.md` | 給使用者看的逐步部署說明（繁體中文） |
| `demo/index.html` | 公開試用頁（不連後端）：手寫簽名、看名冊、下載含簽名的 Excel 範例 |
| `scripts/make_qr.py` | 產生 QR Code：`python3 scripts/make_qr.py <exec網址> <會議名稱> [輸出.png]`（需 `pip install "qrcode[pil]"`） |

## 執行步驟

1. **確認需求**：問使用者會議名稱，以及是否要增減欄位（預設：姓名必填，單位、職稱選填）。要加欄位時，同時修改 `Index.html` 的輸入框、送出的 `payload`，以及 `Code.gs` 的 `submitSignIn()` 與 `getMeetingSheet_()` 標題列。
2. **交付程式**：把 `assets/Code.gs` 與 `assets/Index.html` 交給使用者（或複製到使用者指定的資料夾）。請使用者開一份試算表命名「會議簽到總覽」，**從「擴充功能 → Apps Script」建立專案**（這樣才有「簽到工具」選單）。檔名必須是 `Code.gs` 與 `Index`（HTML 檔，Apps Script 編輯器內不要加 .html）。
3. **帶使用者部署**：照 `references/deploy-guide.md` 一步一步說明。重點：
   - 先執行一次 `setup` 完成授權；出現「Google 尚未驗證這個應用程式」→「進階」→「前往（不安全）」→「允許」。
   - 部署為「網頁應用程式」，**執行身分：我**、**誰可以存取：所有人**。設錯時，與會者會被要求登入，或簽名會存到別人的雲端硬碟。
   - 修改程式後要「管理部署作業 → 編輯 → 新版本」，網址才會更新內容。
4. **產生 QR Code**：請使用者在總覽用「簽到工具 → 建立會議並產生簽到 QR Code」。若使用者直接給你 `/exec` 網址，也可以執行 `scripts/make_qr.py` 產生。
5. **請使用者實測一筆**：用手機掃描簽到，確認雲端硬碟該場會議資料夾出現 PNG 與「簽到表_會議名稱」試算表，且總覽有新增一列。

## 注意事項

- 這個技能只產生程式與說明，不會替使用者登入 Google，也不會代為部署。
- 不要把使用者的 `/exec` 網址、試算表網址或簽到資料提交到任何公開儲存庫。
- 簽到資料含個資（姓名、簽名）。提醒使用者：資料夾不要設為公開分享，會議結束後依單位規定保存或刪除。
- 下載整場簽名：在雲端硬碟對該會議資料夾按右鍵 →「下載」（自動打包成 ZIP）。含簽名的名冊：在總覽選取該場會議 →「簽到工具 → 匯出選取的會議」。
- 儲存格內的簽名圖（CellImage）用試算表內建「檔案 → 下載 → Excel」時可能不會保留，要拿 Excel 請用「簽到工具」匯出（它改用浮動圖片，Excel 與 PDF 都會保留）。
- 後端已處理：同時多人簽到時用 `LockService` 排隊、試算表公式注入防護（=、+、-、@ 開頭會加單引號）、簽名大小上限 2MB。
